Logo e símbolo do Confirma, com o texto já convertido em contorno (Manrope extrabold), prontos para usar sem instalar a fonte.

- `confirma-logo-noite.svg`: versão principal, tinta `noite` (#0B1F1A), para fundos claros.
- `confirma-logo-branco.svg`: tinta branca, para fundos escuros e fotos.
- `confirma-logo-verde.svg`: tinta `verde` (#0A7F50), para peças de marca sobre fundo claro.
- `confirma-simbolo-noite.svg` e `confirma-simbolo-verde.svg`: só o balão com check, para favicon e avatar.
- `confirma-icone-app.svg`: símbolo branco sobre quadrado verde com cantos arredondados, para ícone de app e foto de perfil.

Nos arquivos de uma cor, o check é recortado com a cor do fundo previsto (`nevoa` ou branco). Sobre outro fundo, use a versão adequada em vez de recolorir.
