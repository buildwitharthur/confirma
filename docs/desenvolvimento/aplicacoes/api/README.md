# API

## Propósito

A API atende as integrações dos sistemas clientes, os comandos autenticados do painel e o recebimento de eventos externos do provedor de WhatsApp.

## Tecnologias principais

Node.js, TypeScript, Fastify, PostgreSQL, Prisma e OpenAPI.
