## Registro de conclusão (exemplo)

Antes:

```md
- [ ] **EX-001 — Criar formulário de login**
  - **Commit:** Pendente.
```

Depois:

```md
- [ ] **EX-001 — Criar formulário de login**
  - **Commit:** `a1b2c3d`
```

> `a1b2c3d` é um hash fictício usado somente para demonstrar o formato. Nunca registre esse valor como commit real.

`[ ]` significa tarefa pendente. `[x]` significa tarefa implementada e validada. Cada tarefa deve manter um identificador estável, um critério de aceite e, preferencialmente, um commit lógico. Quando houver vários commits, registre cada hash real. O checklist só deve ser marcado depois da implementação e validação; o hash pode ser acrescentado em uma atualização documental posterior.
