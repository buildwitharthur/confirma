# Ferramentas

| Tecnologia | Responsabilidade |
| --- | --- |
| pnpm | Gerenciamento de dependências e workspaces. |
| Turborepo | Orquestração das tarefas do monorepo. |
| TypeScript | Linguagem principal compartilhada pelas aplicações. |

O monorepo terá configurações compartilhadas para desenvolvimento, validação, testes e builds. Scripts e configurações detalhadas serão definidos posteriormente, quando a implementação for iniciada.
